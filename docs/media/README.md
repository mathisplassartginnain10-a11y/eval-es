# Médias des étapes

Place ici les fichiers référencés dans `src/sections.js` (`docs/media/`).

- **Image** : `jpg`, `png`, `webp`, etc.
- **Vidéo** : `mp4`, `webm`, …

Tu peux mélanger les deux d’un slide à l’autre : dans `KEYFRAMES`, mets `type: "image"` ou `type: "video"` pour chaque étape.

Ancien dossier `docs/videos/` : tu peux déplacer les `.mp4` ici ou ajuster les noms dans `sections.js`.
